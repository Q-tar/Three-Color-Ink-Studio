# 验证记录

## 当前版本：接收固件 1.2（2026-10-31）

环境：Windows x64、Python 3.13.14、ESP-IDF 5.4.4、ESP32-C3；Windows EXE 使用 PyInstaller 6.22.3。

### 自动测试

在 `image_tool` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_core test_gui test_device test_wifi
```

21 项测试通过，覆盖图像位序与颜料极性、横竖屏映射、黑红不重叠、透明背景、导出、裁切、协议分包和坏包恢复，以及 Qt 线程连接、传图保存、重绘、串口异常和存储异常。

Wi-Fi 测试使用真实本地 HTTP 套接字和 Qt 工作线程，设备端由模拟器替代。覆盖握手、上传保存、重绘、CRC 错误、会话事件隔离、POST 响应丢失后不重传、启动标识变化及事件过期。

### 固件构建

- ESP-IDF 5.4.4 构建成功，应用 0xc7b40（817984 字节），1 MiB 应用分区剩余 22%。
- 保留原分区布局、Board2 引脚与屏幕驱动；新增 SoftAP、HTTP 接口及客户端事件记录。
- USB/Wi-Fi 命令通过互斥锁预留唯一刷新任务，HTTP 线程不执行屏幕刷新。
- 已核对 `firmware/bin` 与新版 EXE 附带固件的清单一致，三个固件文件 SHA256 均匹配。

### 上位机与打包

- 输出目录为 `dist/InkStudio-WiFi`，启动及交付脚本默认使用该版本。
- 冻结 EXE 自检通过（ok=true、frozen=true）：预览、USB 模拟握手/传图保存/重绘/断开，以及本地 HTTP 模拟握手/上传保存/重绘。
- 报告：`logs/packaged_self_check.json`、`logs/packaged_wifi_self_check.json`；日志与截图仅保留在本机，不提交 Git。
- 已用 Qt 离屏渲染检查 Wi-Fi 模式切换、地址框及热点说明的布局。
- 打包时隔离外部 PATH，避免混入其他软件的不兼容 ICU/OpenSSL DLL；退出后恢复环境。

### 实物验证范围

用户在使用新版后反馈“可以了”。本次整理与上传不执行烧录。软件测试不能替代对真实屏幕成像、无线供电稳定性、保存后的断电恢复和长期运行的硬件验证；这些项目尚未形成完整的可复现回归记录。

根目录单图显示工程已有此前用户反馈的显示效果，与接收固件分开维护。
